# Disposition方針

| Disposition | 必須根拠 | 次の担当 |
|---|---|---|
| accepted | 対応方針と残余リスク | reviewer |
| rejected-with-evidence | 反証Evidenceと適用範囲 | reviewer |
| fix-submitted | base/result revision、再現手順、テスト | reviewer |
| deferred | 保留理由と再判断条件 | humanまたはreviewer |
| risk-accepted | リスク、承認者、期限 | human/adjudicator |
| not-applicable | 適用外の要件・Evidence | reviewer |

どのDispositionでも、回答者が検証済みや終端状態を宣言してはなりません。
