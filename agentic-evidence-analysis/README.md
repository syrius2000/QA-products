## MarkdownLint 設定

- `.markdownlint.json` は、正本である OSX-IDE-JSON-management の `common/markdownlint/.markdownlint.json` のコピーです（`raw_configs/markdownlint/.markdownlint.json` と同一内容）。

- 正本の所在と配布の仕組みは、OSX-IDE-JSON-management の README「MarkdownLint の正本と配布」を参照してください。
