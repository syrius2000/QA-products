# Quality Loop 実践ケース例 (Examples)

本ディレクトリには、3者協調ガードQMSの代表的な4つのケース例を収録しています。

## 収録ケース一覧

1. **`01-standard-cycle/`**: 正常系（1サイクルで修正・独立検証・Owner受入完了）
2. **`02-evidence-rebuttal/`**: 反論系（Implementerが客観的Evidenceで反論し、Reviewerと合意）
3. **`03-regression-detected/`**: 回帰系（修正によって生じた別の問題をReviewerが検知し新Finding化）
4. **`04-accepted-with-risk/`**: リスク受入系（環境制約等の未解決Findingに対し、Ownerが条件付きで受入裁定）
